# Altium Generic Components

Reusable Altium Designer library containing generic schematic symbols and PCB footprints for common electronic components.

## Contents

- Generic resistors and ceramic capacitors
- Ferrite beads and thermistors
- LEDs and standard, Schottky, and TVS diodes
- PTC fuse
- Generic inductor
- SMT test point

## Usage

1. Clone or download this repository.
2. Open `Altium Generic Components.LibPkg` in Altium Designer.
3. Compile the Integrated Library project.
4. Install the generated `.IntLib` through the Components panel.
5. Place components from the installed library.

For each placed generic component, set:

- Value
- Package
- Manufacturer
- Manufacturer Part Number
